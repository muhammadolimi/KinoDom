Для всех моделей в проекте репозитории создаются по единому шаблону.
Шаблон смотреть по примеру Genre, потому что только там код с комментариями.
В собственных репозиториях НЕЖЕЛАТЕЛЬНО писать комментарии

На текущем этапе необходимо реализовать только:

- интерфейс репозитория
- реализацию репозитория
- регистрацию DI в `Program.cs` (```C# builder.Services.AddScoped<I_____Repository, ____Repository>(); ```)

Контроллеры, dto mapping, validation и crud пока НЕ СОЗДАЮТСЯ !!!

---
# Структура

```txt
Repositories
│
├── Interfaces
│   └── I[model name]Repository.cs <- тут реализация интерфейса
│
└── Implementations
    └── [model name]Repository.cs  <- тут сам интерфейс с 5 методами
```

ВАЖНО!
- Все методы должны быть async
- Использовать Task<>
- Использовать FindAsync, ToListAsync, SaveChangesAsync
- Репозиторий работает только через AppDbContext
- Контроллеры пока НЕ создавать
- Бизнес-логика пока НЕ нужна
- Generic Repository пока НЕ использовать
